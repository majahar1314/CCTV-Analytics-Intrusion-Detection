
# CCTV Analytics – Intrusion Detection for College Campus

## Project Overview
An AI-based CCTV surveillance system that detects
people entering restricted areas of a college campus.

## Technologies Used
- Python
- OpenCV
- YOLO26
- ByteTrack
- NumPy
- Pandas
- Jupyter Notebook

## Features
- Person Detection
- Object Tracking
- Restricted Zone Detection
- Intrusion Alerts
- Screenshot Capture
- CSV Event Reports
- Annotated CCTV Video

## Project Workflow
1. Load CCTV video.
2. Detect people using YOLO.
3. Track people using ByteTrack.
4. Define restricted campus zones.
5. Detect unauthorized zone entry.
6. Generate intrusion alerts.
7. Save screenshots and CSV reports.

## Installation

pip install -r requirements.txt

## Run Project

Open CCTV_Intrusion_Detection.ipynb
and execute the notebook cells in order.

## Output
- Intrusion detection video
- Intrusion screenshots
- CSV event report
